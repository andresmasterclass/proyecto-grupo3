## Ramas

| Rama | Para qué |
|---|---|
| `main` | Versión publicada. Solo recibe cambios desde `develop` |
| `develop` | Integración. Todo entra aquí por Pull Request |
| `frontend` | Página: `index.html`, `css/`, `js/` |
| `backend` | Datos: `datos/equipo.json` |
| `testing` | Casos de prueba: `PRUEBAS.md` |
| `docs` | Documentación: este README |

## Cómo verla en tu computador

1. Clona el repositorio y ábrelo en VS Code.
2. Instala la extensión **Live Server**.
3. Clic derecho en `index.html` › **Open with Live Server**.
